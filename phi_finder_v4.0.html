📋 Methodology & Data Sources
Analysis Pipeline:
1. Fetch live data from public APIs (CORS-proxied where needed)
2. Calculate all meaningful physical ratios (mass, magnitude, frequency)
3. Measure |ratio − φ| distance for each pair
4. Compare to Monte Carlo random baseline
5. Report p-values with full provenance
Data Sources:
🌌 LIGO: gwosc.org (GWOSC Event API)
🌍 Earthquakes: USGS FDSN (M≥4.5, last 30 days)
🔭 Exoplanets: NASA TAP (confirmed planets)
📡 SETI: Synthesized from known frequency candidates
